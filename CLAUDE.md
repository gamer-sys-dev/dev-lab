# Dev lab

Chade's public playground for building and trying out apps that aren't personal or work related. Public repo, hosted free on GitHub Pages.

## Hard rules

- Nothing personal, nothing Catholic Care and nothing from the side income project. Personal apps live in personal-public, personal notes in personal-private.
- No secrets in files. Use GitHub repo secrets if anything needs a key.

## Writing rules

- British English. No em or en dashes. No Oxford comma. No AI vocabulary or patterns.
- Short answers on the phone. Push back on weak ideas.

## How to build here

- One folder per project, grouped loosely (for example games/, tools/, experiments/). Each gets a short README saying what it is.
- Plain HTML, CSS and JavaScript by default so it runs straight from GitHub Pages. Must work on Android and iPhone.
- Add each project to the root index.html.
